Citation
========

If you use ``moirestrain`` in research or engineering reports, cite the software
metadata in ``CITATION.cff`` and the sampling moire method reference relevant
to your work.

Method reference
----------------

Koganemaru, M., Nagato, S., Uchino, M., and Ikeda, T. (2019). Proposal of
Strain Measurement Method for Electronic Packages Using Phase-Shifted Sampling
Moire Method. *Journal of The Japan Institute of Electronics Packaging*,
22(1), 95-102. https://doi.org/10.5104/jiep.22.95

Software citation
-----------------

The repository includes a ``CITATION.cff`` file so GitHub and citation tools
can generate a software citation for the package version being used.
